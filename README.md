# Marshal Portfolio (React + Vite + Framer Motion)

    npm install
    npm run dev

- Content: `src/data.js` (search TODO)
- Design tokens: `src/styles/theme.css` (colors, fonts, radius, easing)
- Layout/styles: `src/styles/global.css`
- Section order: `src/App.jsx`
- Photos: put files in `public/photos/`, reference as `/photos/name.jpg` in `data.js`
- Deploy: `npm run build`, upload `dist/` to Vercel or Netlify
